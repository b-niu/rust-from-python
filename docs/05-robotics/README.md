# 医疗机器人与实时控制专题 (Robotics & Real-time Systems)

本阶段聚焦于机器人运动学、传感器数据流（LiDAR/IMU）以及 ROS 2 实时节点开发。

## 目录建议

- `kinematics-nalgebra.md`：基于 nalgebra 的机械臂正逆运动学解算
- `pointcloud-lidar.md`：LiDAR 点云数据结构、体素滤波与空间索引（k-d Tree）
- `imu-sensor-fusion.md`：IMU 姿态解算与扩展卡尔曼滤波（EKF）
- `ros2-rust-nodes.md`：ROS 2 节点通信：用 r2r / ros2-rust 接入机器人消息总线
